# Project Statement

## Project Title

**Personal Finance Manager**

---

## Problem Statement

Managing personal income and expenses manually can be difficult, especially when there are multiple expenses belonging to different categories.

People may lose track of how much they have spent, how much money is remaining, or whether they are staying within their planned spending limits.

The **Personal Finance Manager** is developed to provide a simple way to record income and expenses, calculate the current balance, and manage category-wise budgets through a Java-based console application.

---

## Scope of the Project

The project focuses on basic personal financial management.

The current system allows users to:

* Create a basic user profile.
* Record income transactions.
* Record expense transactions.
* View all transactions.
* Calculate total income.
* Calculate total expenses.
* Calculate the current balance.
* Create budgets for different categories.
* Check expenses against budget limits.
* View budget usage and remaining amounts.

The current version is designed as a **console-based, in-memory application** and does not include permanent data storage or a graphical user interface.

---

## Target Users

The system is mainly intended for:

* Students who want to track their daily expenses.
* Individuals who want to maintain a simple record of their income and spending.
* Users who want to keep track of category-wise spending limits.

---

## High-Level Features

### 1. User Profile

Allows the user to enter and view basic profile information such as name and email.

### 2. Income Management

Allows users to record income along with its source, date, amount, and description.

### 3. Expense Management

Allows users to record expenses with their category, date, amount, and description.

### 4. Transaction Management

Allows users to view recorded transactions and calculate total income, total expenses, and balance.

### 5. Budget Management

Allows users to create budgets for different expense categories and track their spending.

### 6. Budget Checking

Checks whether an expense is within the available budget for its category.

### 7. Financial Summary

Displays the user's total income, total expenses, current balance, and budget information.

### 8. Input Validation

Performs basic validation to prevent invalid monetary values such as zero or negative amounts.

---

## Main Objective

The main objective of this project is to develop a simple and modular Java application for personal finance tracking while applying Java Object-Oriented Programming concepts in a practical project.

---

**Academic Project**

**Platform:** Console / Terminal
